# 个人起始页使用说明

项目沿用 Deno、原生 TypeScript 和 CSS，没有新增依赖。

## 运行

已安装 Deno 到 `C:\Users\zjc02\.deno\bin\deno.exe`，用户 PATH 已更新。重新打开终端后可直接使用 `deno`。

```powershell
deno task online
```

打开 `http://localhost:8000/`。浏览器扩展可用 `deno task build` 构建，再在扩展管理页加载 `release/chrome` 或 `release/edge`。

## 搜索与应用页面

- 搜索框左侧默认只提供 Google、Bing、百度，与设置中的引擎保持一致，没有“默认”或“自定义”入口。
- 在搜索设置中填写引擎名称及包含 `%s` 的 HTTP(S) 搜索地址即可添加其他引擎（最多 20 个），同名保存会更新地址，支持移除。只有保存后的命名引擎才会加入切换菜单。
- 搜索框默认宽度为 44em（原为 30em），仍可在设置中调整；支持方向键和 Escape。左侧统一使用搜索图标，引擎以纯文字显示，不依赖外部图标接口。
- 同一输入框查找所有页面和文件夹内的应用；选择结果直接打开应用，直接回车使用当前网页搜索引擎。
- 在搜索设置中点击“启用书签搜索”，授权后可查找浏览器书签；网页版仅支持应用和网页搜索。
- 应用区 `+` 创建命名页面，页面名称右键菜单支持重命名等操作，沿用原有拖拽排序和跨组移动能力。
- 页面切换只影响应用，时钟、天气、搜索保持固定。记住上次使用的页面；原有置顶分组仍会跨页显示。
- 轻量布局保留上方留白，可在页面间距附近关闭“紧凑布局”。

## 语言

默认跟随浏览器提供的系统语言优先列表，每次打开页面重新匹配。支持 `zh-CN`、`zh-Hans`、`zh-Hant` 等地区和文字标签；系统语言改变时自动刷新。语言设置中可选择“跟随系统语言”，也可手动指定语言作为覆盖。旧配置未指定语言模式时也会跟随系统。网页无法直接读取操作系统配置，使用浏览器暴露的语言偏好。

## 天气

进入“天气与问候”设置，在“天气数据源”选择 UAPI，填写城市或 6 位行政区编码，在密钥栏填写 `uapi-` 开头的密钥，点击“保存并测试天气”。支持接口本身允许的无密钥访问；如返回 401，需要填写有效密钥。

调用完整地址 `https://uapis.cn/api/v1/misc/weather`，使用 GET，密钥仅通过 `Authorization: Bearer …` 请求头传递。行政区编码优先于城市，均留空时由服务端按 IP 定位，不会向该接口传递未记载的经纬度参数。请求实时天气、体感温度及多日预报，并适配项目的华氏/摄氏设置。

“自定义 API”支持同样的查询参数和 UAPI 兼容 JSON，最少返回：

```json
{ "temperature": 18.3, "weather": "晴", "city": "北京" }
```

可选 `feels_like`、`temp_max`、`forecast` 等字段与所提供的 UAPI 文档一致。温度源数据必须为摄氏度，不能是字符串。未返回预报时隐藏预报，不伪造温度。原文档没有给出其引用的完整图标枚举表，所以保留原始天气文字，并使用保守的天气文字匹配来选择本地图标。

密钥仅存本机，并绑定服务器来源；同步更换接口地址后需重新保存相应密钥。请求有 12 秒连接超时，处理 400、401、403、404、429、500、503；限流遵守 Retry-After，失败时保留可用的同来源缓存。扩展首次连接新接口会请求该服务器的访问权限。

## WebDAV 与完整备份

在设置管理中将同步类型设为 WebDAV，填写服务地址、用户名、密码/应用密码。备份目录默认是 `Bonjourr`，可编辑，留空则直接使用服务地址。点击“保存并测试连接”，按钮下方会显示测试中、成功或失败及原因。测试或上传时会自动创建缺失的备份目录，服务地址本身需已存在。服务器需要支持标准 PROPFIND、MKCOL、GET、PUT 和条件请求。

例如服务地址为 `https://example.com/dav/`、备份目录为 `Bonjourr`，备份会保存到 `/dav/Bonjourr/`。旧配置仍使用原目录，不会额外嵌套一层 `Bonjourr`。

- **上传同步**：创建或更新 `bonjourr-latest.json`。首次连接已有文件时先下载；使用 ETag 和 If-Match 防止覆盖其他设备的变更。
- **下载同步**：先展示恢复确认，再在本机缓存完整恢复副本，随后恢复远端数据。不会自动拉取或覆盖。
- **另存快照**：在同一目录写入带时间戳的独立文件，不覆盖同步文件。可在 WebDAV 客户端下载该文件，再用“导入完整备份”恢复。
- **导出/导入完整备份**：可脱离服务器使用，包含设置、应用/文件夹、本地壁纸、缩略图和自定义图标，最大 50 MB。
- **恢复覆盖前数据**：从本机恢复上次下载或导入前的完整副本。

天气密钥、Gist token、WebDAV 用户名和密码均不进入完整备份。凭据仍保存在各设备本机。普通原有 JSON 配置导出仍只导出设置，不包含本地壁纸。

WebDAV 为手动双向同步。网页版受浏览器跨域规则约束，服务器需允许当前页面来源、PROPFIND/MKCOL/GET/PUT、Authorization/Depth/If-Match/If-None-Match/Content-Type，并暴露 ETag 响应头。扩展版按用户操作请求对应服务器权限。若服务器不提供强 ETag，无法安全覆盖已有同步文件，可使用独立快照。

## 验证

```powershell
deno task format
deno task types
deno task test
deno task build
```

自动化测试覆盖接口参数、温度转换、预报缺失、HTTP 错误与限流、搜索本地应用、WebDAV 认证/条件请求，以及包含本地资源的备份恢复。真实 WebDAV 账号由使用者在设置中填写。
