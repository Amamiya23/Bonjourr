## Design Context

### Users
Personal browser start page for daily searching and access to applications.

### Brand Personality
Quiet, simple and personal. Preserve Bonjourr's existing visual character.

### Aesthetic Direction
Keep the clock's current starting position and generous space above it. Reduce the space occupied by weather and search without pushing the interface against the top edge. Preserve both themes and user font choices.

### Design Principles
- Keep time, weather and unified search outside application pagination.
- Switch only applications and quick links between named pages.
- Group related information while preserving breathing room between sections.
- Reveal configuration and secondary actions when needed.
- Keep local credentials outside portable settings and backups.
